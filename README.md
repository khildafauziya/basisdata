Repositori ini menyimpan kode sumber Java untuk penyelesaian tugas pemrograman. Proyek ini mendemonstrasikan tiga kemampuan teknis utama.
1 Pembuatan struktur data Stack dengan metode Last In First Out.
2 Pembuatan struktur data Queue dengan metode First In First Out.
3 Pengurutan kumpulan angka dengan algoritma Quick Sort.

Daftar File Kode
1 MainStack.java menjalankan proses penambahan dan penghapusan data pada tumpukan.
2 MainQueue.java menjalankan proses penambahan dan penghapusan data pada antrean.
3 MainQuickSort.java menjalankan proses partisi dan pengurutan nilai.
